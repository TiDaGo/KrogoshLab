# KrogosLab

**Overlay editor for OBS** — build stream overlays from widgets right in your browser: text, rotating messages, follower/viewer counters, countdown timers, a stopwatch and chat, on top of your own SVG designs with effects and view rotation.

**Редактор оверлеев для OBS** — собирайте оверлеи для стрима из виджетов прямо в браузере: тексты, сменяющиеся сообщения, счётчики подписчиков и зрителей, таймеры, секундомер и чат — поверх своих SVG-дизайнов, с эффектами и ротацией видов.

## How it works / Как это работает

1. Run KrogosLab — it lives in the system tray and opens the editor in your browser.
   Запустите KrogosLab — он живёт в трее и открывает редактор в браузере.
2. Drag widgets onto the canvas, set them up, save the scene.
   Перетащите виджеты на холст, настройте, сохраните сцену.
3. Copy the overlay URL and add it to OBS as a **Browser** source.
   Скопируйте URL оверлея и добавьте его в OBS как источник «Браузер».

Twitch and YouTube data is fetched by the app on your computer; tokens never leave it and are never sent to the overlay.
Данные Twitch и YouTube получает программа на вашем компьютере; токены никуда не уходят и в оверлей не передаются.
